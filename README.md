# Verilog RTL & Digital Design Learning Lab 🚀

Welcome to my hardware description language (HDL) portfolio! This repository serves as a structured log documenting my growth in digital circuit design, register-transfer level (RTL) engineering, and functional verification strategies.

## ⚠️ The Laws of My Digital Lab
1. **The First Rule of RTL:** If it works on the first try, something is deeply, terrifyingly wrong with the testbench.
2. **Propagation Delay:** The exact amount of time it takes for me to realize I forgot a semicolon.


## 🎯 Portfolio Objectives
*   **RTL Design:** Implementing optimized combinational and sequential logic.
*   **Verification:** Writing robust, self-checking testbenches to validate functional accuracy.
*   **Industry Workflows:** Adhering to professional folder structures and tracking simulations with waveform captures.

## 🛠️ Toolchain & Environment
*   **HDL Language:** Verilog (IEEE 1364-2005)
*   **Simulation & Tool:**  Synopsys VCS, Icarus Verilog via EDA Playground
*   **Waveform Viewer:** EPWave / GTKWave
